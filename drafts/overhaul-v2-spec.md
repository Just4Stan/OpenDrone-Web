# TITLE BLOCK — final re-skin spec (council-merged)

**Verdict:** TITLE BLOCK won 2–1 (brand judge + feasibility judge). The storefront becomes one dense, beautiful engineering document: every page a numbered sheet with hairline rules instead of cards, the catalog a drawing register you can buy from, the footer a literal KiCad title block displaying its own git revision, gold demoted from button paint to a highlighter stroke. It is unfakeable brand truth for a company whose product is published KiCad files, it structurally solves the placeholder-image problem (a hatched register cell looks intentional; an empty card never does), and it is the cheapest direction at the highest craft ceiling — tokens + rules + type, minimal library risk.

**Grafts folded in from the losing proposals (all judge-endorsed):**
- **From OD-1:** SegmentedControl detent physics generalized from HeroSizeSlider (sheet tabs + theme/lang flick switches); pure-CSS keycap press on filled-gold CTAs; SignalLost 404 consumes shared tokens (one system, not two dialects); dot-grid backdrop behind board renders; edge-light hover replaces pointer-follow spotlights repo-wide; "delete JS writers with their CSS consumers in the same PR" rule.
- **From SLOT MAP:** `slotForHandle()` + `CompatBadge` (registry-derived mount/size/model chips) on register rows and the PDP ordering table; cart companion logic re-seated as hatched "missing position" ghost rows; fail-closed `useComingSoon` price gating on every NEW price-bearing surface (PR #269 bug class). **Skip** the full SlotMapDiagram chrome — 4+ dashed "reserved" slots at launch reads as vaporware for a pre-launch one-man company.
- **From EXPLODED VIEW:** hero scroll-driver migration (hand-rolled wheel/touch hijack → ScrollTrigger scrub+snap on native scroll) as its own behavior-identical lane; `app/lib/gsap.ts` pattern (SSR-guarded dynamic import mirroring `heroScenePromise`, plugins registered once, `withScrub` helper baking in `gsap.matchMedia('(prefers-reduced-motion: no-preference) and (min-width: 769px)')` so mobile bundles never see GSAP); one ScrambleText decode on the footer REV cell (identifiers-decode, whileInView once — counts against the easter-egg budget, needs Stan's sign-off since ScrambleText was declared 404-only); `AnimatedNumber` rolls on the PDP price at variant change and cart totals at qty change (motion states a fact at the exact moment it changes); `app/lib/home-content.ts` single source for HOME_LEDGER + tagline.

**Judge-2 dissent, addressed as mitigations (novice-on-a-phone lens):** register rows keep real imagery — 96px thumbs desktop / 64px mobile, plus a desktop hover "plate" preview (larger render in a callout panel on dot-grid); CompatBadge chips answer "does this fit my build" structurally; homepage hero + PDP galleries remain full image stages; the REV/SHEET/FIG/ITEM/DOC label vocabulary is isolated in one `docAnnotations` constant module for a single Stan review, and every layout must read fine with labels dropped (values alone still work: `02 · a1b2c3f · 2026-07-06`).

**Hard constraints (restated, non-negotiable):** all copy verbatim — Stan writes every word; new visible strings must be derived data (file numbers, SKUs, commit hashes, dates, prices, registry mounts/sizes, Shopify productType) never prose; colors only via semantic tokens, every surface working in both dark and `html.light`; Inter + JetBrains Mono + Tokyo only; motion@12 base engine, GSAP only where specified, never both on one element; `MotionConfig reducedMotion="user"` global and untouched; commerce machinery (coming-soon lock, notify-me, cart semantics, `cart.$lines` share links, quick-add/stack offers) restyled, never rewired; HeroScene / BoardArt / FrameViewer / board renders recomposed, never deleted or duplicated.

## 1. The three system moves

1. **De-round + de-float.** Rounded pods, blurs, drop shadows → opaque square(ish) panels bounded by 1px hairlines. Structure comes from rules, not elevation.
2. **Mono becomes the structural voice.** JetBrains Mono promoted to all chrome: nav, labels, table cells, buttons, prices, footers, annotations. Inter reserved for headlines and body prose. Tokyo stays exclusively on brand-name tokens (`BrandName`).
3. **The annotation layer.** Every surface gains a data-derived documentation stratum: doc numbers (`OD-{fileNumber}` from `PRODUCT_CONTENT.fileNumber`), figure plates (`FIG {chapterNum}-1`), revision readouts (from `LatestCommit`), sheet counters, zone ticks. Generated from data already in the repo. The fixed label vocabulary (REV/SHEET/FIG/ITEM/QTY/DOC) is chrome, isolated in `docAnnotations`, flagged for Stan's sign-off in one review pass.

## 3. Typography & layout system

- **Mono microtype scale** (JetBrains Mono, uppercase, tracked): `.doc-annot` 10px/0.14em (zone ticks, figure plates, sheet counters, `--color-ink-annot`); `.doc-label` 11px/0.18em (eyebrows, table headers, nav, buttons); `.doc-cell` 13px/0.02em with `font-variant-numeric: tabular-nums slashed-zero` (every table cell, price, spec value).
- **Inter** only for `--fs-xl+` headlines (existing clamp scale) and `product-hero-lead`/`chapter-body` prose.
- **Numbered headings:** chapters render existing `number` props as a mono prefix cell separated by a hairline (`3 | TEARDOWN`). Data exists; no CSS counters.
- **Rules as layout:** section breaks are full-bleed 1px `--color-hairline` rules with the `.doc-label` sitting ON the rule (bg-padding trick). Ruled tables use `gap: 1px; background: var(--color-hairline)` grid + `background: var(--color-bg)` cells — theme-safe by construction.
- **`SheetFrame.tsx`** (new, ~80 lines): absolute-inset hairline rectangle at `--sheet-inset`, corner registration crosses (pseudo-elements), optional zone ticks (A–D / 1–6). `pointer-events: none`, `aria-hidden`, hidden <480px. Used ONLY on: homepage hero, PDP gallery, chapter media figures, 404. Frames are for exhibits, not chrome.
- **Dot-grid utility** `.dot-grid`: radial-gradient dots at 12px pitch, `--color-grid-dot` — backdrop for board renders in media frames, hover plates, and hatched-adjacent media cells.
- **Keycap CSS** `.keycap`: `:active { transform: translateY(var(--keycap-travel)) }` + shadow collapse, pure CSS, applied to filled-gold CTAs (Shop, Add to cart, Checkout, Notify me, Subscribe). User-initiated — doesn't violate "documents don't bounce".
- **Edge-light hover** `.edge-light`: border brightens to `--color-border-strong` + primary ink lifts to `--color-text`; row surfaces additionally get a `--color-highlight` background wash. Pure CSS transitions. Replaces ALL pointer-follow spotlight machinery — delete `--spot-x/--spot-y` JS writers together with their CSS consumers in the same PR, repo-wide (ProductItem, RelatedProducts, product-card).
